导航项 Nav Item

一级导航的最小单元。选中态由 aria-current 或 is-selected 驱动，左侧指示条宽度由 --component-nav-indicator-w 决定，樱雾玻璃风格将其设为 0 即隐藏。

导航分组 Nav Group

把导航项按业务域分组，组标题使用大写字母间距。

搜索框 Search Field

角色检索。外层容器使用 :focus-within 承载聚焦态，内部 input 自身不显示轮廓，避免双焦点环。

角色列表项 Entity Item

头像加两行文本。选中态同时改变底色与边框色，保证在纯色风格下也能辨识。

分段切换 Segmented

对话与群聊的模式切换，选中项通过 aria-selected 标记。

面板分区 Panel Section

上下文侧栏的每一块。标题左对齐、当前值右对齐、说明文字弱化。
