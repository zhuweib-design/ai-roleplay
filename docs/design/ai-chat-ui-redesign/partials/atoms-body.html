字体与字号阶梯

基准字号 14px，行高 1.5。中文优先使用系统中文字体，英文使用风格化字体栈。

--font-size-display / 44px开始与 Seraphina 的对话
--font-size-3xl / 34px标题层级三
--font-size-2xl / 26px标题层级二
--font-size-xl / 20px标题层级一
--font-size-lg / 16px角色名与区块标题
--font-size-md / 14px正文基准，用于消息气泡与描述
--font-size-sm / 13px控件标签与列表主文字
--font-size-xs / 12px辅助说明与徽章
--font-size-2xs / 11px最小可读字号，仅用于元信息

图标

24x24 线性 SVG，描边宽度由 --icon-stroke-w 控制，颜色继承 currentColor。不使用 emoji 或字体图标。

按钮

变体 primary / soft / ghost / danger / dashed，尺寸 sm / md / lg / block。悬停、聚焦、按下、禁用状态由伪类真实驱动。

图标按钮

正方形点击区，尺寸 sm 28 / md 36 / lg 44。44px 为无障碍最小可点尺寸。

徽章 Badge
