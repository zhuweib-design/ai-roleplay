# AI 虚拟对话界面重构 · 十三套风格设计系统

对一个 1920 x 1080 的 AI 虚拟对话产品界面做完整重构，交付十三套可切换的 UI 风格、
一套 Token 驱动的组件库、真实落地的响应式断点，以及配套的可执行前端实现规格。

十三套风格分两组：**通用风格** 5 套（面向通用产品），**二次元风格** 8 套（面向 ACG 场景）。

## 1. 核心结论

| 项目 | 结果 |
|---|---|
| 风格数量 | 13 套（通用 5 + 二次元 8） |
| 基准画布 | 1920 x 1080 |
| 区域划分 | 4 个一级区域，17 个子区域 |
| 响应式断点 | 6 档，已用真实 CSS 实现并可验证 |
| L1 结构 Token | 183 个（`css/tokens.base.css`） |
| L2 + L3 主题 Token | 142 个 x 13 套 = 1846 个（`css/theme-*.css`） |
| 组件 | 原子 20 类 / 分子 12 类 / 组织 7 个区域 |
| 组件层硬编码 | 0 处（颜色、间距、时长全部为 0） |
| 未定义 Token 引用 | 0 处 |
| 图标 | 45 个内联线性 SVG，无 emoji、无字体图标 |

十三套风格**共用同一份 DOM 与同一份组件 CSS**，差异 100% 由 Token 表达。
新增一套风格只需新增一个 `theme-*.css`（142 个 Token），无需改动任何组件代码。
第二轮新增的四套与第一轮的二次元四套都是这样加进来的：组件层一行未改。

## 4. 二次元风格的设计依据

赛璐璐（Cel Shading）的核心技法是「平涂底色 + 一层硬边阴影 + 高光 + 描线」，
这四项被逐条映射到 UI Token：

| 动画技法 | UI 映射 | Token |
|---|---|---|
| 平涂底色 | 大面积纯色背景，不用渐变 | `--color-bg-*` |
| 硬边阴影 | 无模糊的偏移阴影 | `--component-card-shadow` |
| 高光 | 顶部 1px 白色内阴影 | `--shadow-inset` |
| 描线 | 2px 深蓝紫描边（非纯黑） | `--color-border-default` |
| 网点阴影 | 12px 周期网点纸背景 | `--component-backdrop-image` |
| 明暗分界 | 按钮 46% 处硬切的双色平涂 | `--component-button-primary-bg` |

魔法少女、霓虹东京、机甲三套则分别对应「渐变与发光」「霓虹与光晕」「警示色与硬边」三种语言。

## 6. 实现约定（强制）

1. **组件层零字面量**：`layout.css`、`components.css`、`responsive.css`、`overview.css`、`demo.css` 中
   不允许出现十六进制颜色、`rgb()/hsl()`、`px` 数值、`ms/s` 时长。
2. **零值也走 Token**：写 `var(--space-0)` 而不是 `0`，避免出现「零值可以例外」的破窗。
3. **动态值走运行时 Token**：进度百分比用 `--progress-value`，滑块填充用 `--slider-fill`，
   画布缩放用 `--stage-scale`。
4. **断点尺寸也走 Token**：媒体查询阈值是 CSS 规范硬限制（无法用变量），已在校验脚本中豁免；
   但断点内部覆写的所有尺寸都来自 `tokens.base.css` 的断点专用 Token。
5. **状态用 ARIA 属性驱动**：选中态使用 `aria-current` / `aria-selected` / `aria-pressed`，
   样式与语义绑定，不依赖纯视觉类名。
6. **图标不用 emoji**：全部为内联线性 SVG，描边宽度由 `--icon-stroke-w` 控制。

以上约定由 `tools/check-tokens.mjs` 自动校验，当前全部通过。

## 7. 重新构建与校验

```bash
# 生成十三套风格页面与分组总览
node tools/build-pages.mjs

# 生成原子 / 分子 / 组织组件展示页
node tools/build-components.mjs

# 重新生成 Token 规范文档（十三套对照表从 CSS 实时解析）
node tools/gen-token-doc.mjs

# 重新生成十三套风格设计文档
node tools/gen-style-docs.mjs

# Token 合规性校验（硬编码扫描 + 未定义引用 + 内联样式检查）
node tools/check-tokens.mjs
```

新增一套风格只需两步：

1. 复制任意 `css/theme-*.css` 改名为 `theme-<新id>.css`，替换 `[data-theme]` 选择器与 142 个 Token 值
2. 在 `tools/site.mjs` 的 `THEMES` 数组里加一行（含 `group` 字段），重新运行构建脚本

组件层不需要任何改动。

## 8. 已知限制

1. 这是**纯静态前端规格**，不含任何网络请求、状态管理或后端接口。
2. 界面文案全部为简体中文，未做国际化结构。
3. 群聊模式、消息流有消息时的完整形态未经原图验证，见 `docs/06-不确定项.md`。
4. 断点的**具体数值**仍是设计决策（原图只有 1920 x 1080），需要产品复核；但断点行为已可实测。
5. 原截图的精确色值无法获取（有损压缩），十三套风格均为重新设计，不声称还原原色。
6. 二次元风格中的窄体字（机甲）与圆体字（赛璐璐、魔法少女）依赖系统已安装字体，
   未安装时回退到黑体，风格特征会减弱。
7. 使用了 `:has()`、`backdrop-filter`、CSS 自定义属性，建议目标浏览器为
   Chromium 105+ / Safari 15.4+ / Firefox 121+。
