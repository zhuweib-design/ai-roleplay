### 3.2 状态实现方式说明

- **悬停与聚焦使用 CSS 伪类真实驱动**，不做静态截图。浏览 `components/*.html` 时把鼠标移到控件上、或用 Tab 键切换焦点，即可看到真实状态。
- **禁用状态使用真实属性**（`disabled` 或 `aria-disabled="true"`），并同时设置 `pointer-events: none` 与 `cursor: not-allowed`。
- **选中状态统一使用 ARIA 属性**（`aria-current`、`aria-selected`、`aria-pressed`）作为选择器钩子，样式与语义绑定，不依赖纯视觉类名。
- 所有状态切换的过渡时长来自 `--duration-fast`（140ms）或 `--duration-normal`（220ms），曲线为 `--ease-standard`。

## 4. 交互与无障碍基线

| 项目 | 规范 | Token |
|---|---|---|
| 最小可点尺寸 | 44 x 44px | `--size-control-touch` |
| 焦点可见 | 键盘聚焦必须显示焦点环，鼠标点击不显示 | `--focus-ring-width` = 2px |
| 焦点偏移 | 常规元素外偏移 2px，内嵌元素用负偏移 | `--component-focus-offset` |
| 对比度 | 正文文字与背景对比度不低于 4.5:1 | 见各主题 L2 文字色 |
| 动效降级 | `prefers-reduced-motion: reduce` 时全部动画与过渡降为 0.01ms | `--duration-motion-off` |
| 图标语义 | 纯图标按钮必须带 `aria-label`；装饰性图标带 `aria-hidden="true"` | — |
| 表单标签 | 每个输入控件都有 `label`（视觉隐藏时使用 `.visually-hidden`） | — |
| 数字对齐 | 数值使用等宽数字，避免跳动 | `font-variant-numeric: tabular-nums` |
| 滚动条 | 细滚动条，滑块色随主题 | `--scrollbar-size` 等 |

## 5. 图标规范

- 全部为 24 x 24 视窗的线性 SVG，来源为项目自带的 `tools/icons.mjs`，共 45 个图标
- 描边宽度由 `--icon-stroke-w`（1.6）统一控制，颜色继承 `currentColor`
- 生成时内联进 HTML，避免 `file://` 协议下 SVG sprite 跨文件引用失效
- **不使用 emoji、不使用字体图标、不使用装饰性字符**
