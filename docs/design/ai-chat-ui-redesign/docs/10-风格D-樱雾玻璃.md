# 10 风格 D：樱雾玻璃 Sakura Glass

> 明亮柔和 · 超大圆角 · 彩色投影

| 项目 | 内容 |
|---|---|
| 风格 ID | `d`（对应 `[data-theme="d"]`） |
| 英文名 | Sakura Glass |
| 关键词 | 樱花、雾、玻璃、圆润、轻盈、温柔 |
| 适用场景 | 轻量陪伴对话、女性向产品、白天使用、对信息压迫感敏感的用户 |
| Token 文件 | `css/theme-d.css` |
| 完整页面 | `style-d.html` |

## 1. 设计意图

- 浅紫粉雾底（#F6F3FB）配白色玻璃卡片，主色樱花粉（#E5678F），辅色鸢尾紫（#8B7CF6），点缀暖橙（#F0A73C）。
- 圆角阶梯被整体放大：小到 8px，大到 36px，按钮与胶囊全部为 999px 全圆。这是本风格最强的识别特征。
- 阴影不使用黑色，而是低透明度的紫灰色（rgba(120,100,170,...)），形成柔和的彩色投影，避免浅色界面上的脏灰感。
- 导航项的左侧指示条宽度设为 0（--component-nav-indicator-w: 0px），选中态完全依靠圆角胶囊底色表达，与整体圆润语言一致。
- 环境层是三层柔和径向渐变（粉、紫、橙），让白色卡片下方透出淡彩。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-3px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

深紫文字 #2C2740 在白底上对比度约 12.9:1。但弱文字 #948EAC 在白底上对比度约 3.1:1，仅可用于 14px 以上的辅助信息，不建议用于正文。所有可点元素使用 999px 圆角，需确保焦点环在圆角边缘仍然可见（已通过 outline-offset 处理）。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-d.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="d"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-d.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-d.css`，请勿手工修改数值。
