## 1. 设计意图

- 把原图的深色基调推向更精致的玻璃拟态：以靛黑夜色为底，面板之间靠 1px 弱边框与轻微底色差区分，而不是靠重阴影。
- 主色采用极光紫（#8B7CF6），辅色青绿（#4FD1C5），并把原图的玫红（#F2568C）降级为点缀色，只出现在角色头像色调与少量强调处。这样既保留原图的情绪记忆，又避免大面积玫红带来的视觉疲劳。
- 环境层使用三层径向渐变模拟极光，叠加在应用最底层，不干扰任何文字对比度。
- 卡片与输入框使用半透明底 + 背景模糊，让极光在玻璃下透出，这是本风格最核心的质感来源。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-2px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

主文字 #ECEEF7 在底色 #0A0B14 上对比度约 16:1，远超 WCAG AAA。紫、青、玫红三色仅用于强调与状态，不承担正文可读性。玻璃层的模糊半径 18px，在低端设备上可降级为纯色底（把 --component-glass-blur 设为 0px）。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-a.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="a"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-a.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-a.css`，请勿手工修改数值。
