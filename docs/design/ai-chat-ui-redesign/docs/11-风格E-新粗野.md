> 硬边框 · 硬阴影 · 零圆角 · 高饱和撞色

| 项目 | 内容 |
|---|---|
| 风格 ID | `e`（对应 `[data-theme="e"]`） |
| 英文名 | Neo Brutal |
| 关键词 | 粗野、印刷、硬边框、硬阴影、高饱和、直白、贴纸感 |
| 适用场景 | 游戏化对话、年轻向社区、需要强视觉记忆点的产品、内容量中低的场景 |
| Token 文件 | `css/theme-e.css` |

## 1. 设计意图

- 用 2px 墨黑描边与 4px 无模糊硬阴影建立「印刷品」般的物理感，元素像贴纸一样压在纸面上，而不是浮在背景之上。
- 全部圆角归零，包括按钮、卡片、头像、输入框与标签。这是本风格最强的识别特征，也是它与另外四套最直接的区隔。
- 导航栏整块使用亮黄（#FFE94A），选中项反转为黄底黑字，形成强烈的区域标识；这一做法牺牲了克制感，换取了极高的可发现性。
- 主色电光蓝（#2B5BFF）承担主操作与焦点，辅色品红（#FF5C8A）用于角色头像色调，点缀黄用于强调底色。三个颜色饱和度都在 80% 以上，互不调和。
- 阴影的模糊半径为 0（4px 4px 0），按下时元素向阴影方向位移、阴影收缩，模拟真实的按压反馈，这是本风格唯一「动」的部分。
- 环境层是 45 度斜纹，模拟印刷网点，只在留白处可见，不干扰文字。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-2px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

墨黑 #111111 在米白 #EFE9DC 上对比度约 15.8:1，亮黄底 #FFE94A 上的墨黑文字对比度约 14.2:1，均达到 WCAG AAA。硬阴影不带模糊，不会造成文字边缘发虚。需要注意两点：一是 2px 全包围描边在高信息密度界面中会增加视觉噪声，建议仅用于中低密度场景；二是电光蓝主按钮上的白字对比度约 5.1:1，满足 AA 但未达 AAA。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-e.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="e"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-e.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-e.css`，请勿手工修改数值。
