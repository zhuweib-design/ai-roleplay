# 17 风格 K：水彩治愈 Watercolor Healing

> 淡彩晕染 · 柔和漫反射 · 纸纹

| 项目 | 内容 |
|---|---|
| 风格 ID | `k`（对应 `[data-theme="k"]`） |
| 英文名 | Watercolor Healing |
| 关键词 | 水彩、治愈、淡彩、晕染、纸面、柔和、手绘 |
| 适用场景 | 轻小说向、日常治愈题材、长时间阅读、需要降低视觉压力的场景 |
| Token 文件 | `css/theme-k.css` |
| 完整页面 | `style-k.html` |

## 1. 设计意图

- 水彩纸白底配四团柔和径向晕染（蓝、橙、绿、紫），模拟颜料在湿纸上扩散的边界模糊感。
- 主色是低饱和的水彩蓝 #4A7C96，辅色水彩橙、点缀水彩绿，三色都刻意压过饱和度，避免数码感。
- 阴影全部带大模糊半径与低透明度（0 8px 24px / 0.12），模拟纸面漫反射，全文件没有硬边阴影。
- 圆角中等偏大（8-32px），按钮与标签为全圆，整体柔和但不像魔法少女那样甜腻。
- 标题使用圆体，正文使用无衬线，兼顾手绘感与长文可读性。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-2px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

主文字 #4A4A44 在水彩纸白 #FAF7F0 上对比度约 10.4:1，达到 AAA。主按钮白字在 #4A7C96 上约 4.6:1，满足 AA。四团晕染的透明度都控制在 0.10-0.16，不会干扰文字可读性。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-k.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="k"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-k.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-k.css`，请勿手工修改数值。
