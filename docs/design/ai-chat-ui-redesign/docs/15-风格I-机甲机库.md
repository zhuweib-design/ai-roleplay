# 15 风格 I：机甲机库 Mecha Hangar

> 枪灰金属 · 警示黄 · 工业硬边

| 项目 | 内容 |

## 1. 设计意图

- 枪灰金属底（#15181C）配警示黄（#FFB000）与 HUD 青（#4FC3F7），模拟机库维修面板的配色。
- 卡片顶部有一条 3px 实心警示黄条（inset 阴影实现），是工业设备「危险区域」标记的 UI 化，也是本风格最强的识别特征。
- 全部圆角归零或极小（0-6px），标题字体使用 Barlow Condensed 窄体并强制大写、加 0.06em 字距，模拟仪表盘刻字。
- 主按钮用黄底深色字（#1A1400），对比度约 11:1，符合工业场景的高可视性要求。
- 环境层是 45 度黄黑警示斜纹，透明度仅 0.055，只提供质感不干扰阅读。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-1px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

主文字 #DCE2E8 在底色 #15181C 上对比度约 12.6:1，达到 AAA。警示黄底配深色字约 11:1。需注意：Barlow Condensed 是窄体，中文会回退到系统字体，因此中文阅读体验与其他风格一致，窄体效果主要体现在拉丁字母与数字上。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-i.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="i"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-i.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-i.css`，请勿手工修改数值。
