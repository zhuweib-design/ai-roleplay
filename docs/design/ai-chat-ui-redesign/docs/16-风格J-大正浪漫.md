# 16 风格 J：大正浪漫 Taisho Roman

> 和纸纹样 · 朱红描金 · 衬线标题

| 项目 | 内容 |
|---|---|
| 风格 ID | `j`（对应 `[data-theme="j"]`） |
| 英文名 | Taisho Roman |
| 关键词 | 大正、和纸、朱红、金、七宝纹、衬线、复古 |
| 适用场景 | 和风题材、历史向角色扮演、需要书籍感与仪式感的场景 |
| Token 文件 | `css/theme-j.css` |
| 完整页面 | `style-j.html` |

## 1. 设计意图

- 和纸米色底配墨绿深色导航栏，朱红作主色、金作点缀，标题与正文统一使用衬线体，这是全项目唯一通篇衬线的风格。
- 导航栏是项目里第一套深色侧栏（墨绿 #2A3B33），通过新引入的 --component-rail-* Token 组实现，文字色、悬停底色、分隔线全部独立于内容区。
- 边框改用金色（rgba(168,135,31,0.35)）替代常规灰黑描边，呼应大正时期的莳绘与金箔工艺。
- 环境层是两组 45 度交叉斜线构成的七宝纹，周期 7px，透明度 0.055，模拟和纸纤维与织物纹样。
- 圆角压到 2-12px，按钮不带阴影，靠 1px 金边与底色区分层级。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-1px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

墨褐 #2E2620 在和纸米色 #F5EDE0 上对比度约 12.9:1。深色导航栏内浅色文字 #C4BAA2 在墨绿 #2A3B33 上约 7.4:1，达到 AAA。朱红主按钮白字约 5.2:1，满足 AA。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-j.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="j"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-j.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-j.css`，请勿手工修改数值。
