# 02 页面区域树与布局规格

## 1. 基准画布

| 项目 | 取值 | Token |
|---|---|---|
| 画布宽 | 1920px | `--size-app-w` |
| 画布高 | 1080px | `--size-app-h` |
| 画布容器 | `.stage`，水平居中，超出部分由外层 `.stage-shell` 承载 | — |
| 视口小于基准时 | 由 `js/stage-scale.js` 读取 `--size-app-w/h` 等比缩放，写入 `--stage-scale` | `--stage-scale` |

## 3. 栅格定义

```css
.app {
  display: grid;
  grid-template-columns:
    var(--size-rail-w)      /* 176px 区域 A */
    var(--size-list-w)      /* 275px 区域 B */
    minmax(0, 1fr)          /* 自适应 区域 C */
    var(--size-context-w);  /* 352px 区域 D */
  grid-template-rows: minmax(0, 1fr);
  width: 100%;
  height: 100%;
}
```

四栏合计固定宽度 176 + 275 + 352 = 803px，区域 C 实际可用宽度为 1920 - 803 = 1117px。

视口小于 1920px 时，`css/responsive.css` 会按断点覆写上述列宽，
并在 ≤ 1279px 时把区域 D 改为绝对定位的右侧抽屉（脱离栅格流，栅格降为三列）。
完整断点行为见第 05 篇。

## 4. 区域规格明细

### 4.1 区域 A 一级导航栏 `.rail`

| 项目 | 取值 |
|---|---|
| 布局方式 | flex 纵向三段式：标题（不收缩）/ 导航（`flex: 1 1 auto` + 纵向滚动）/ 底部（不收缩） |
| 容器宽度 | 固定 176px（`--size-rail-w`），高度撑满 |
| 内边距 | 标题区与底部区左右 `--padding-panel`（16px）；导航区上 8px、左右 12px、下 16px |
| 外边距 | 无 |
| 间距 | 导航项之间 `--gap-stack-xs`（4px）；分组之间 `--space-4`（16px） |
| 对齐 | 导航项内部：图标与文字左对齐，行高 36px；分组标题左对齐并缩进 12px |
| 滚动 | `.rail__nav` 纵向滚动，`overflow-x: hidden` |
| 背景 | `--color-bg-rail`，右侧 1px 分隔线 |

### 4.2 区域 B 角色列表栏 `.list-pane`

| 项目 | 取值 |
|---|---|
| 布局方式 | flex 纵向三段式：搜索（不收缩）/ 列表（`flex: 1 1 auto` + 纵向滚动）/ 底部操作（不收缩） |
| 容器宽度 | 固定 275px（`--size-list-w`） |
| 内边距 | 搜索区 12px 12px 8px；列表区上 4px、左右 12px、下 20px；底部区 12px |
| 外边距 | 无 |
| 间距 | 列表项之间 4px；分组之间 16px；虚线按钮与上一项间距 4px |
| 对齐 | 列表项：头像左对齐、文本块 `flex: 1`、名称与副标题左对齐并截断 |
| 滚动 | `.list-pane__body` 纵向滚动 |
| 背景 | `--color-bg-list`，右侧 1px 分隔线 |

### 4.3 区域 C 会话主区 `.main`

| 子区域 | 布局方式 | 容器最大宽度 | 内边距 | 外边距 | 间距 | 对齐 |
|---|---|---|---|---|---|---|
| C1 顶栏 | flex 横向两端对齐 | 无（撑满 1117px） | 左右 20px，高 64px | 无 | 两端组内 12px | 左端组左对齐，右端组右对齐 |
| C2 状态条 | flex 横向，左侧固定 + 右侧横向滚动 | 无 | 上下 8px，左右 20px，最小高 40px | 无 | 元素间 8px | 垂直居中 |
| C3 消息流 | flex 纵向居中，内容水平居中 | `--size-content-max-w` = 760px | 上下 24px，左右 20px | 无 | 内容块之间 24px | 空态整体水平居中，并在剩余高度内垂直居中 |
| C4 输入区 | flex 纵向 | `--size-composer-max-w` = 860px | 上 16px、左右 20px、下 20px | 无 | 文本域与操作行之间 8px | 操作行两端对齐 |

区域 C 各子区域均以 1px 分隔线上下分隔，分隔线样式由 `--component-divider-style` 决定。

### 4.4 区域 D 上下文侧栏 `.context-pane`

| 项目 | 取值 |
|---|---|
| 布局方式 | flex 纵向：标题（不收缩，高 56px）/ 内容（`flex: 1 1 auto` + 纵向滚动） |
| 容器宽度 | 固定 352px（`--size-context-w`） |
| 内边距 | 标题区左右 16px；内容区四周 16px |
| 外边距 | 无 |
| 间距 | 分区之间 `--gap-section`（32px）；分区内部 12px |
| 对齐 | 分区标题左对齐、当前值右对齐；统计行两端对齐 |
| 内容最大宽度 | `--size-context-inner-max-w` = 320px |
| 滚动 | `.context-pane__body` 纵向滚动 |
| 背景 | `--color-bg-panel`，左侧 1px 分隔线 |

## 5. 滚动容器清单

| 容器 | 方向 | 说明 |
|---|---|---|
| `.rail__nav` | 纵向 | 导航项超出时滚动，横向禁止 |
| `.list-pane__body` | 纵向 | 角色列表超出时滚动 |
| `.main__body` | 纵向 | 消息流滚动 |
| `.main__statusbar-scroll` | 横向 | 状态胶囊过多时横向滚动，不换行、不挤压主区 |
| `.context-pane__body` | 纵向 | 上下文分区滚动 |

滚动条宽度 `--scrollbar-size`（10px），滑块色 `--color-scrollbar-thumb`，轨道透明。

## 6. 层叠顺序

| 层 | Token | 取值 | 用途 |
|---|---|---|---|
| 装饰层 | `--z-base` | 0 | `.app__backdrop` |
| 内容层 | `--z-raised` | 10 | 四个区域 |
| 吸顶 | `--z-sticky` | 100 | 顶栏、状态条 |
| 遮罩 | `--z-overlay` | 200 | 抽屉遮罩 |
| 模态 | `--z-modal` | 300 | 对话框 |
| 浮层 | `--z-popover` | 400 | 下拉菜单 |
| 提示 | `--z-tooltip` | 500 | 工具提示 |
| 轻提示 | `--z-toast` | 600 | 全局提示 |

## 7. 对齐基线

- 所有区域标题、分区标题左对齐于其容器内边距
- 所有「当前值 / 数值」右对齐，并使用 `font-variant-numeric: tabular-nums` 保证数字列对齐
- 所有图标与相邻文字垂直居中，间距 `--gap-inline-sm`（8px）或 `--gap-inline-md`（12px）
- 列表项内的名称与副标题均为单行截断（`text-overflow: ellipsis`）
