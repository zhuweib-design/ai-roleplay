# 08 风格 B：墨纸 Ink and Paper

> 浅色阅读 · 直角细线 · 近乎无动效

| 项目 | 内容 |
|---|---|
| 风格 ID | `b`（对应 `[data-theme="b"]`） |
| 英文名 | Ink and Paper |
| 关键词 | 纸、墨、印章、阅读、克制、专注 |
| 适用场景 | 长文本角色扮演、写作辅助、白天办公环境、需要长时间阅读的场景 |
| Token 文件 | `css/theme-b.css` |
| 完整页面 | `style-b.html` |

## 1. 设计意图

- 把对话界面还原成「读书」的体验。底色是暖纸白（#FAF8F3）而非纯白，减少屏幕反光与刺眼感。
- 形状语言是直角系：圆角最大只到 10px，卡片与输入框基本是 4-6px。边框用 1px 实线，取消所有模糊与光晕，取消卡片悬停抬升（--component-card-lift 为 0）。
- 强调色只有一个：朱砂红（#B23A2F）。它像印章一样克制地出现在主按钮、选中态与焦点环上。
- 动效被压缩到近乎瞬时：过渡时长保持 140ms 但位移量为零，仅做颜色与边框的切换，符合「纸不会动」的直觉。
- 标题使用衬线字体（Noto Serif SC 回退到宋体），正文使用无衬线，形成书籍式的层级对比。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `0px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

墨黑 #1C1A17 在纸白 #FAF8F3 上对比度约 15.6:1，达到 WCAG AAA。所有状态不依赖颜色单一维度：选中态同时改变底色与边框色，禁用态同时降低透明度并禁用指针事件。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-b.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="b"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-b.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-b.css`，请勿手工修改数值。
