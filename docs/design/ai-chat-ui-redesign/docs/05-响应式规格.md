# 05 响应式规格（已实现）

> 本版为**已落地实现**，不再是推测。实现位置：`css/responsive.css`。
> 原截图只有 1920 x 1080 单一尺寸，因此断点的**具体数值**仍是设计决策，需要产品复核；
> 但断点行为已可通过浏览器缩放实际验证，验证截图见 `preview/_resp-*.png`。

## 1. 断点定义

采用桌面优先（Desktop First）。四栏并置是高信息密度创作工具的核心价值，因此优先保障宽屏体验，再逐级降级。

| 断点 | 视口宽度 | 媒体查询 | 画布行为 | 栏位 | 验证截图 |
|---|---|---|---|---|---|
| XL 基准 | ≥ 1920px | 无 | 固定 1920 x 1080 | 四栏 | `preview/style-a.png` |
| L | 1440 - 1919px | `max-width: 1919px` | 转为自适应铺满视口 | 四栏 | — |
| M | 1280 - 1439px | `max-width: 1439px` | 自适应 | 四栏收窄 | `preview/_resp-1440.png` |
| S | 1024 - 1279px | `max-width: 1279px` | 自适应 | 三栏 + 侧栏抽屉 | `preview/_resp-1024.png` |
| XS | 768 - 1023px | `max-width: 1023px` | 自适应 | 图标导航 + 列表 + 主区 | `preview/_resp-768.png` |
| 2XS | < 768px | `max-width: 767px` | 自适应 | 单栏 + 底部导航 | `preview/_resp-600.png` |

## 2. 各断点的具体变化

### 2.1 L（≤ 1919px）：画布转为自适应

```css
@media (max-width: 1919px) {
  .stage { width: 100%; height: 100vh; margin: var(--space-0); transform: none; }
  .app { height: 100%; }
}
```

四栏宽度保持不变（176 / 275 / 自适应 / 352），主区可用宽度随视口收缩。
空态内容最大宽度 760px 与输入区最大宽度 860px 会自动生效。

### 2.2 M（≤ 1439px）：三栏收窄

- 尺寸 Token 覆写：导航栏 `--size-rail-w-md`（168px）、列表栏 `--size-list-w-md`（260px）、侧栏 `--size-context-w-md`（320px）
- 顶栏右端**用量徽章最先隐藏**（`.badge--mono`），因为它优先级最低
- 开场白容器最大宽度放宽到 `--size-composer-max-w`

### 2.3 S（≤ 1279px）：侧栏转抽屉

- 列表栏收至 `--size-list-w-s`（248px），侧栏收至 `--size-context-w-s`（288px）
- **上下文侧栏转为右侧抽屉**：绝对定位、`translateX(100%)` 移出屏幕，`[data-context="open"]` 时滑入
- 栅格由四列改为三列，抽屉脱离栅格流
- 遮罩层 `.app__scrim` 在抽屉展开时淡入
- 顶栏低优先级图标按钮隐藏：`.icon-btn[data-priority="low"]`（搜索、导出）；面板按钮保留
- 主区横向内边距由 20px 收至 16px
- 空态主标题由 26px 降至 20px

> 决策依据：若在 1024px 才收起侧栏，三栏加侧栏会把主区压到 400px 以下，
> 顶栏的分段控件会被迫换行。因此侧栏抽屉化提前到 1279px。

### 2.4 XS（≤ 1023px）：导航栏转图标模式

- 导航栏宽度由 168px 收至 `--size-rail-collapsed-w`（64px）
- 隐藏 `.nav-item__label`、`.nav-item__count`、`.nav-group__title`、`.rail__header`
- 导航项改为居中排列，分组之间用 8px 间距分隔
- 列表栏收至 `--size-list-w-xs`（240px）
- 顶栏分段控件（对话 / 群聊）隐藏

### 2.5 2XS（< 768px）：单栏堆叠

- 栅格改为单列 + 底部一行：`grid-template-rows: minmax(0,1fr) auto`
- **导航栏转为底部导航条**：横向排列、可横向滚动、隐藏底部固定区
- **角色列表转为全屏页**：默认隐藏，`[data-view="list"]` 时覆盖全屏
- 顶栏左端出现列表切换按钮 `.main__list-toggle`（其他断点隐藏）
- 选中角色后自动回到会话视图
- 消息气泡最大宽度由 78% 提升到 88%
- 开场白改为纵向堆叠、通栏
- 输入区底部叠加 `env(safe-area-inset-bottom)` 安全区

## 3. 触摸设备

```css
@media (hover: none) {
  .btn:hover, .starter:hover, .card--interactive:hover { transform: none; }
}
```

无悬停能力的设备上取消依赖悬停的位移反馈，避免「按下后停在悬停态」的错觉。

## 4. 断点尺寸的 Token 化

媒体查询的阈值（如 `max-width: 1439px`）是 CSS 规范硬限制，**无法使用 `var()`**，只能字面量书写。
除此之外，断点内部覆写的所有尺寸都来自 Token：

| Token | 值 | 用途 |
|---|---|---|
| `--size-rail-w-md` | 168px | M 断点导航栏 |
| `--size-list-w-md` | 260px | M 断点列表栏 |
| `--size-context-w-md` | 320px | M 断点侧栏 |
| `--size-list-w-s` | 248px | S 断点列表栏 |
| `--size-context-w-s` | 288px | S 断点侧栏 |
| `--size-list-w-xs` | 240px | XS 断点列表栏 |
| `--size-rail-collapsed-w` | 64px | XS 断点图标导航 |
| `--size-context-drawer-w` | 320px | 抽屉宽度 |

`tools/check-tokens.mjs` 已对 `@media` 阈值行做显式豁免，其余行仍执行零字面量校验。

## 5. 与等比缩放模式的关系

两条路径**互斥**，默认走响应式重排：

| 模式 | 触发方式 | 行为 | 适用场景 |
|---|---|---|---|
| 响应式重排（默认） | 直接打开页面 | 走 `css/responsive.css`，真实断点降级 | 真实产品使用 |
| 等比缩放 | URL 追加 `?fit=scale` | 整块 1920 x 1080 画布按视口等比缩小 | 设计评审、截图比对 |

`js/stage-scale.js` 默认直接返回，只有检测到 `?fit=scale` 时才启用缩放。

## 6. 组件级响应式汇总

| 组件 | XL | M | S | XS | 2XS |
|---|---|---|---|---|---|
| 导航栏 `.rail` | 176px 图标+文字 | 168px | 168px | 64px 仅图标 | 底部横条 |
| 列表栏 `.list-pane` | 275px | 260px | 248px | 240px | 全屏页 |
| 上下文栏 `.context-pane` | 352px 常驻 | 320px 常驻 | 288px 抽屉 | 抽屉 | 全屏抽屉 |
| 主区顶栏右端 | 全部显示 | 隐藏用量徽章 | 再隐藏搜索/导出 | 再隐藏分段控件 | 仅保留面板按钮 |
| 状态条胶囊 | 横向滚动 | 同左 | 同左 | 同左 | 同左 |
| 开场白 | 3 + 1 换行 | 2 + 2 | 2 + 2 | 逐行 | 纵向通栏 |
| 消息气泡 | 78% | 78% | 78% | 78% | 88% |

## 7. 交互配套脚本

| 脚本 | 职责 |
|---|---|
| `js/panel-toggle.js` | 切换 `.app` 的 `data-context`（抽屉）与 `data-view`（列表页）；Esc 关闭抽屉；监听 `matchMedia` 在宽屏自动展开侧栏 |
| `js/slider-fill.js` | 计算滑块填充比例并写入 `--slider-fill`，同步数值显示 |
| `js/stage-scale.js` | 仅在 `?fit=scale` 时启用等比缩放 |
