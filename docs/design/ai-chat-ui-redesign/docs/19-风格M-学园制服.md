# 19 风格 M：学园制服 School Uniform

> 藏青领巾红 · 苏格兰格 · 清爽

| 项目 | 内容 |

| 适用场景 | 校园题材、青春向角色扮演、需要干净利落观感的场景 |

## 1. 设计意图

- 清爽白底配藏青深色导航栏（#1F2E4A），领巾红（#C0392B）作主色、徽章金（#B8941F）作点缀。
- 导航栏是项目里第二套深色侧栏，复用 --component-rail-* Token 组，与内容区的配色完全解耦。
- 环境层是 15px 周期的双向下格子纹，对应制服裙的苏格兰格。
- 圆角压到 3-14px、按钮不带阴影，靠 1px 边框与底色区分层级，整体干净利落。
- 头像与卡片使用小圆角方形（6px）配藏青描边，对应学生证照片的观感。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-1px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

主文字 #232B38 在清爽白 #F4F6F9 上对比度约 13.8:1，达到 AAA。深色导航栏内浅色文字 #B8C2CE 在藏青 #1F2E4A 上约 7.8:1，达到 AAA。领巾红主按钮白字约 5.0:1，满足 AA。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-m.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="m"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-m.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-m.css`，请勿手工修改数值。
