# 13 风格 G：魔法少女 Magical Girl

> 粉紫渐变 · 发光光晕 · 全圆角

| 项目 | 内容 |
|---|---|
| 风格 ID | `g`（对应 `[data-theme="g"]`） |
| 英文名 | Magical Girl |
| 关键词 | 魔法少女、渐变、发光、星光、全圆角、高饱和 |
| 适用场景 | 情感陪伴、女性向产品、轻量社交、需要强情绪感染力的场景 |

## 1. 设计意图

- 高饱和粉紫双主色，主按钮使用 135 度粉紫渐变，是全项目唯一使用渐变按钮的风格。
- 圆角阶梯整体放大到 10-40px，导航项、按钮、标签、输入框全部使用全圆（999px），形成彻底的圆润语言。
- 发光代替阴影：卡片与头像的光晕来自主色的低透明度扩散，而不是黑色投影，这让浅色界面不会出现脏灰。
- 环境层是粉、紫、金三层径向渐变，模拟魔法阵的光晕，为纯白卡片提供彩色底衬。
- 导航项的左侧指示条宽度设为 0，选中态完全依靠圆角胶囊底色表达，与整体圆润语言一致。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-3px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

深紫 #4A2B5C 在浅粉白 #FDF2FF 上对比度约 12.4:1。主按钮白字在渐变两端分别约 4.6:1 与 5.2:1，满足 AA。弱文字 #9E85B4 在白底上约 3.4:1，仅可用于 14px 以上的辅助信息。全圆角元素需确保焦点环在弧形边缘仍可见，已通过 outline-offset 处理。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-g.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="g"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-g.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-g.css`，请勿手工修改数值。
