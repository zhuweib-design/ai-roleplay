# 18 风格 L：蒸汽波 Vaporwave

> 深紫霓虹 · 透视网格 · 90 年代

## 1. 设计意图

- 深紫底配荧光粉与青，主按钮使用 135 度粉到青的渐变，配合深色字以获得足够对比度。
- 环境层分三层：底部向上的粉青渐变（模拟地平线）、34px 周期的双向青色网格（模拟透视地面）。
- 与霓虹东京的区别：蒸汽波的光晕更柔、更宽（34-64px），并叠加了青色内辉光，追求朦胧的复古感而非锐利的赛博感。
- 标题字距放宽到 0.04em，配合中等圆角（4-28px），对应 90 年代海报的排版语言。
- 饱和度提升到 1.6，是所有风格里最高的一档，对应蒸汽波的浓艳审美。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-2px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

主文字 #F0E6FF 在底色 #1A0B2E 上对比度约 14.2:1，达到 AAA。渐变按钮配深色字 #1A0B2E，在粉色端约 5.5:1、青色端约 9:1。需注意：网格纹理叠加大面积渐变可能导致背景亮度不均，重要文本应放在卡片内而非直接置于背景之上。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-l.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="l"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-l.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-l.css`，请勿手工修改数值。
