# 14 风格 H：霓虹东京 Neon Tokyo

> 深蓝紫夜 · 霓虹粉青 · 赛博网格

| 项目 | 内容 |
|---|---|

| 英文名 | Neon Tokyo |
| 关键词 | 霓虹、赛博、夜城、粉青撞色、光晕、网格 |
| 适用场景 | 赛博题材角色扮演、夜猫子用户、需要强氛围感与未来感的场景 |

## 1. 设计意图

- 深蓝紫夜色底（#0A0A1F）配霓虹粉（#FF2E88）与霓虹青（#00E5FF），模拟雨夜里霓虹招牌的撞色。
- 发光代替阴影：所有层级由主色的多层光晕（10px / 30px / 60px 递进）表达，全文件没有一处黑色投影。
- 主按钮用亮粉底配深色字（#0A0A1F），既保住霓虹的亮度，又把对比度拉到 5.4:1，避免了白字在霓虹粉上只有 3.7:1 的问题。
- 环境层是 44px 周期的青色网格加两团霓虹光斑，网格提供赛博质感，光斑提供纵深。
- 卡片使用半透明底加内侧青色辉光，让背景网格透出来，形成「玻璃幕墙」的观感。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-2px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

主文字 #EDE9FF 在底色 #0A0A1F 上对比度约 16.8:1，达到 AAA。霓虹粉底配深色字约 5.4:1，满足 AA。需注意两点：一是大面积高饱和霓虹在暗环境下可能造成眩光，建议提供亮度调节；二是青色边框在深底上的对比度约 2.6:1，属于装饰性描边，不承担信息传达。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-h.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="h"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-h.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-h.css`，请勿手工修改数值。
