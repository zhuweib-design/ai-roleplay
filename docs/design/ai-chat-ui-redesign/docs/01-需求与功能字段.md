# 01 需求与功能字段

## 1. 任务定义

对一张 1920 x 1080 的 AI 虚拟对话产品截图做界面重构设计，输出：

1. 不低于 3 套可切换的完整 UI 风格（本项目交付 4 套）
2. 可执行的前端实现规格（区域树、区域规格、设计 Token、组件清单、响应式推测、不确定项）
3. 每套风格各自独立的 Token 样式文件、静态 HTML 页面、设计文档、组件展示页

约束：只使用 Token，禁止在组件层硬编码颜色与间距；页面必须用组件搭建。

## 5. 组件覆盖率结论

截图中出现的全部可见控件，均已落到组件库中的具名组件，不存在「为页面单独写一次性样式」的情况。四套风格页面共用同一份 DOM 片段 `partials/page-body.html`，仅替换 `css/theme-*.css`。
