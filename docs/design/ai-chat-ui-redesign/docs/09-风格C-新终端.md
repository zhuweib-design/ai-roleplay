# 09 风格 C：新终端 Neo Terminal

> 纯黑 HUD · 全等宽字形 · 扫描线

| 项目 | 内容 |
|---|---|
| 风格 ID | `c`（对应 `[data-theme="c"]`） |
| 英文名 | Neo Terminal |
| 关键词 | 终端、HUD、扫描线、等宽、信号、机械感 |
| 适用场景 | 技术用户、高密度信息浏览、键盘流操作、极客审美偏好者 |
| Token 文件 | `css/theme-c.css` |
| 完整页面 | `style-c.html` |

## 1. 设计意图

- 纯黑底（#05070A）配荧光青（#38F2C8）与信号绿（#7CFF6B），字形全部为等宽字体，中英文同宽，形成终端般的栅格感。
- 形状语言是彻底的直角：所有圆角为 0-4px。层级不靠阴影表达，而靠 1px 细线与辉光（box-shadow 的光晕形态）。
- 环境层是一条 3px 周期的横向扫描线纹理（repeating-linear-gradient），透明度极低（0.045），只提供质感不干扰阅读。
- 标题使用 0.10em 字距并强制大写，模拟终端标签的排版。
- 分隔线使用虚线（--component-divider-style: dashed），呼应终端的分节符。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `0px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

荧光青 #38F2C8 在纯黑上对比度约 13.4:1。但需注意两点：一是全等宽中文字形偏窄，长文阅读舒适度低于其他三套，建议仅用于短文本场景；二是荧光色在高亮度屏幕上可能产生眩光，建议提供亮度调节。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-c.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="c"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-c.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-c.css`，请勿手工修改数值。
