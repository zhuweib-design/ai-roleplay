# 12 风格 F：赛璐璐 Cel Shade

> 动画平涂 · 双色硬切 · 网点纸

| 项目 | 内容 |
|---|---|
| 风格 ID | `f`（对应 `[data-theme="f"]`） |
| 英文名 | Cel Shade |
| 关键词 | 赛璐璐、平涂、硬边分界、网点、动画描线、明暗两段 |
| 适用场景 | ACG 角色扮演、动画改编产品、需要强动画质感的年轻向应用 |
| Token 文件 | `css/theme-f.css` |
| 完整页面 | `style-f.html` |

## 1. 设计意图

- 把动画的赛璐璐上色技法直接映射到 UI：底色大面积平涂，明暗之间是硬边分界而不是渐变过渡。
- 主按钮采用上下双色硬切分（46% 处断开），上半是受光面、下半是阴影面，是全项目唯一用「两段式平涂」表达按钮的风格。
- 描线使用深蓝紫（#2A2438）而不是纯黑。动画描线很少用纯黑，深蓝紫能让画面更透气，这一点直接照搬到边框上。
- 卡片与按钮顶部带一条白色高光（inset 阴影），对应动画角色的高光区，让平面色块产生「上亮下暗」的体积暗示。
- 环境层是 12px 周期的网点纸，对应赛璐璐动画里用网点表现阴影的工艺。

## 7. 动效

时长与曲线阶梯全站共享，定义在 `css/tokens.base.css`：

| 场景 | 时长 Token | 曲线 Token |
|---|---|---|
| 颜色 / 边框切换 | `--duration-fast`（140ms） | `--ease-standard` |
| 底色 / 阴影 / 位移 | `--duration-normal`（220ms） | `--ease-standard` |
| 进度条填充 | `--duration-slow`（360ms） | `--ease-standard` |
| 加载指示器 | `--duration-slower`（600ms） | `--ease-linear` |
| 环境呼吸动画 | `--duration-ambient`（12s） | `--ease-standard` |

本风格的动效强度特征：位移幅度由 `--component-card-lift` 控制，当前值为 `-2px`。
开启 `prefers-reduced-motion: reduce` 后，全部时长降为 `--duration-motion-off`（0.01ms）。

## 8. 无障碍评估

深蓝紫 #2A2438 在暖白 #FFF6EC 上对比度约 14.2:1，达到 WCAG AAA。主按钮白字在 #3468D1 上约 4.7:1、在 #1E4FA8 上约 6.5:1，双色分界处最不利情况仍满足 AA。2px 描边在浅色底上提供了强轮廓，对低视力用户友好。

## 9. 如何切换到本风格

完整页面（已内置）：直接打开 `style-f.html`。

接入自有页面：在 `html` 或 `body` 上设置 `data-theme="f"`，并引入样式：

```html
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/tokens.base.css">
  <link rel="stylesheet" href="css/theme-f.css">
  <link rel="stylesheet" href="css/layout.css">
  <link rel="stylesheet" href="css/components.css">
</html>
```

> 本文件由 `tools/gen-style-docs.mjs` 生成，第 2 至 7 节的数值实时取自 `css/theme-f.css`，请勿手工修改数值。
