## 1. 设计目标与范围

### 1.1 目标
在保留现有桌面端完整能力、复用现有 Web 降级代码的前提下，让「AI 酒馆」在手机上成为**可安装、可用于核心对话主流程**的 App 体验。

| 维度 | 目标 |
|---|---|
| 可安装 | 浏览器"添加到主屏幕"，独立全屏窗口运行 |
| 主流程 | 新建/进入会话、对话、切换角色、逛市场——手机上流畅顺手 |
| 触控 | 拇指可达、目标尺寸达标、防误触 |
| 一致性 | 沿用现有深色主题与品牌色，不做风格割裂 |

### 1.2 本期范围（核心导向）
- 底部导航替换桌面左侧栏
- 会话列表、聊天详情、角色浏览、市场浏览：移动专属布局
- 触控目标、字号、安全区适配

### 1.3 后续范围（全面响应式，本期不做）
- 世界书/编辑器/数据探查/设置全子页的移动重构
- 浏览器内本地向量模型（走网关，离线对话暂不支持）

## 2. 移动端设计原则

| 原则 | 说明 |
|---|---|
| 拇指热区 | 主要操作集中在屏幕中下部（红色热区），顶部仅放次要操作/标题 |
| 触控尺寸 | 可点目标 ≥44×44px；间距 ≥8px，防误触 |
| 信息密度 | 单屏聚焦一个任务，列表行高度紧凑但可读 |
| 对比度 | 沿用现有深色主题，正文/次要文字符合可读性 |
| 减动效 | 尊重 `prefers-reduced-motion`，过渡 ≤120ms |

## 3. 移动端信息架构与导航

### 3.1 导航：桌面左侧栏 → 移动底部栏
桌面端是左侧竖栏 + 宽屏多列。手机上改为**固定底部导航栏**，拇指自然触达。

**底部导航 5 Tab（icon + 2 字标签）**

```
[会话] [角色] [市场] [世界书] [设置]
```

| Tab | 目标页 | 说明 |
|---|---|---|
| 会话 | 会话列表 | 默认着陆页，新建会话入口 |
| 角色 | 角色浏览 | 卡片流 |
| 市场 | 社区市场 | 从中可进入角色详情/直接开始会话 |
| 世界书 | 世界书库 | 台账+设定浏览 |
| 设置 | 设置面板 | 模型网关/主题/PWA 信息 |

**交互规则**
- 底部栏固定底部，不随滚动隐藏（避免误触、保持可达）
- 当前 Tab 高亮（品牌色），未激活低饱和
- 与 iOS 安全区底部垫高（避开 Home 横条）
- 聊天详情二级页**不显示底部 Tab**（沉浸式，顶部返回 + 角色名），提供独立返回路径

### 3.2 二级 / 详情页导航
- 顶部返回箭头 + 页面标题
- 聊天、角色详情、市场条目详情等二级页，隐藏底部导航
- 深色遮罩无法替代返回——保证系统返回手势可用（`vue-router` 栈 + 手势）

## 4. 核心页面移动化设计

### 4.1 会话列表
**布局**
- 顶部：页面标题「会话」+ 右上「＋」新建按钮
- 列表：单列会话卡片行，含头像、会话名、最近消息摘要、时间
- 长按 / 左滑：删除、置顶（本期至少支持删除）

**交互**
- 下拉刷新：重新加载会话列表
- 点击行 → 进入聊天详情
- 空态：友好引导「新建第一个会话」，配品牌插画/文案

### 4.2 聊天详情（最核心）
**布局（自上而下）**
1. 顶部栏：返回 + 角色头像 + 角色名 + 状态点（在线/推理中）
2. 消息区：流式滚动，气泡左（角色）右（用户）；时间分隔
3. 底部输入区：输入框 + 发送按钮；可附「工具/上传」按钮（次要）

**交互要点**
- 输入框自动增高（多行），**随键盘弹起贴合**，不被键盘遮挡
- 发送：显式按钮（比回车更手机上友好）；输入框内回车换行
- 长按消息：复制 / 重发 / 删除
- 生成中：角色气泡显示「…」打字指示 + 可停止生成
- `.chat input`：`font-size ≥16px` 防止 iOS 聚焦自动放大
- 底部安全区：键盘/Home 条避让，输入无遮挡

### 4.3 角色浏览
**布局**
- 顶部分类筛选 chips（横向滑动）
- 双列卡片网格，卡片含头像、名称、一句话简介
- 卡片点击 → 详情；详情内「开始对话」直达聊天

**交互**
- 卡片触控区整卡可点，目标高度达标
- 网格栅格滑动流畅，图片懒加载

### 4.4 社区市场
**布局**
- 顶部分类 + 搜索
- 瀑布/双列卡片流，含类型角标、作者、版本
- 支持远程市场下载入口（沿用现有）

### 4.5 设置
**布局**
- 单一可滚动分组列表（模型网关、主题、PWA/关于）
- 表单控件在移动端全宽、触控友好

## 5. 响应式断点与布局网格

| 断点 | 布局 |
|---|---|
| ≤640px（手机） | 底部导航 + 单列/双列卡片 + 全宽输入 |
| 641–1024px（平板） | 底部导航保留或转侧栏，卡片列数可增 |
| ≥1025px（桌面） | 沿用现有左侧栏 + 多列，不改变 |

> **断点口径唯一来源**：`docs/design/design-system-specification.md`（代码侧为 `src/core/viewport.ts` 与 `src/styles/tokens-responsive.css`）。
> 本节为引用，不再自述另一套边界（旧版 `<640 / 640–1024 / >1024` 的表述已按 `≤640 / 641–1024 / ≥1025` 更正）。

**规则**
- 断点用 CSS `@media`，避免 JS 探测
- 卡片网格列数随宽度自适应，不硬编码
- 关键组件（导航、输入区、列表行）提供移动专属 CSS 类，桌面不受影响

## 6. 触控规范

| 项 | 规范 |
|---|---|
| 可点目标最小尺寸 | 44×44px（导航项、按钮、列表行） |
| 图标按钮 | 内嵌 svg，外衬 ≥44px 热区 |
| 相邻目标间距 | ≥8px，避免误触 |
| 手势 | 下拉刷新、上滑列表、返回手势，均需可发现且不冲突 |
| 悬停态 | 手机无效，采用按压反馈（`active`）+ 无 :hover 依赖 |

## 12. PWA 技术设计（第 2 节，`vite-plugin-pwa`）

### 12.1 依赖与接入
- 新增 devDependency：`vite-plugin-pwa`
- `vite.config.ts` 注册 `VitePWA({...})` 插件；**仅在纯 Web 构建启用**（`isTauriEnv` 时禁用，避免 file:// 下 SW 无意义/报错）

### 12.2 manifest 配置
| 字段 | 值 |
|---|---|
| name / short_name | AI 酒馆 / AI酒馆 |
| display | `standalone`（独立全屏窗口） |
| theme_color | `#0B0B10`（沿用现有） |
| background_color | `#0B0B10` |
| start_url | `/` |
| scope | `/` |
| icons | `pwa-192x192.png`、`pwa-512x512.png`、`apple-touch-icon.png` |

图标资源：`public/pwa-192x192.png`、`public/pwa-512x512.png`、`public/apple-touch-icon.png`（用简单 SVG 主题图标生成，占位）

### 12.3 Service Worker 缓存策略
| 资源 | 策略 | 理由 |
|---|---|---|
| 构建产物 `/assets/*.js,css,svg,woff2,img` | `precache` + `StaleWhileRevalidate` | 秒开 + 自动更新 |
| `index.html` | `NetworkFirst`（回退缓存 / 离线 fallback） | 弱网/离线可开壳 |
| 网关 `/v1/chat`、`/v1/embeddings`（远程 AI API） | **不缓存**（不入 runtime cache） | 实时对话，避免陈旧数据 |
| IndexedDB 业务数据 | **不接入 SW** | 由应用自身 IndexedDB 管理 |

`workbox` 关键项：
- `globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}']`
- `navigateFallback: '/'`（SPA 路由离线回退）
- 不注册 runtime 缓存 `urlPattern` 到 `/v1/` 路径

### 12.4 更新策略
- `registerType: 'autoUpdate'`：SW 检测到新版本自动更新（无需用户手动刷新）
- 首访后后台下载更新，下次加载生效

### 12.5 与非 PWA(桌面)隔离
- Tauri（file://）构建注入 `disable: true`，不生成 manifest/SW
- 纯 Web 构建正常生成 PWA

## 13. 移动端导航与响应式实现（第 3 节）

### 13.1 底部导航组件
- 新增 `src/components/mobile/BottomNav.vue`，CSS 级响应式（`@media (max-width: 640px)` 显示）
- 5 个入口：会话 `chat`、角色 `character-list`、市场 `community-market`、世界书 `worldbook`、设置 `settings`

- ≥641px（平板 + 桌面）：显示左侧 NavRail

- 断点口径见 `docs/design/design-system-specification.md`；代码侧唯一来源为 `src/core/viewport.ts`，组件内禁止 `matchMedia`

### 13.4 核心页移动化
