心理活动（旁白段）文风与样式样板

读法：每格是一台 390px 宽的手机屏幕。同一套文字分别用四种排法呈现——三种候选样式（A 竖线 / B 斜体缩进 / C 纯空行）加一种现状对照（心理混在气泡里、气泡内斜体）。 判定目标有两个：一、文风对不对（叙述是否读起来像第一人称小说、角色是否不自称"我"）；二、排法选哪个。 人称口径："我"永远指用户，虚拟角色在旁白里用名字（或"她/他"）指代，绝不用"我"；对白里（标记外）角色可以自称"我"。 配套规则与验收断言见 docs/design/OPT_PLAN_2026-10-15_移动端与五项体验重构.md 第 6 节。

方案 A · 气泡外 + 左竖线（文档推荐态）

心理段完全退出气泡：没有气泡底、不吃气泡那 16px 内边距。竖线与气泡左侧那条 2px 辅色边取同一 x（实测对齐，不外突），"退出感"来自它没有底色、字号降一档、颜色降一档，以及正文比气泡正文靠左几个像素（实测数字见下方规格表）。不用斜体——中文正文里的斜体读起来像译制片。

你这么早就来了？等很久了吧。

我下周可能要去别的城市，短时间回不来。
那是好事，机会难得。

方案 C · 气泡外 + 纯空行与缩进（最无装饰）

没有竖线、没有斜体，只靠留白与行高（1.85）把它和对白分开。最像小说正文，代价是与对白的区分度最低，长对话里容易被扫读成对白。

要你定的四件事（定了才能进实现）

1. 排法选 A / B / C 哪个。我的默认选 A：区分度够、又不把心理做成"卡片"，且竖线方向与 AI 气泡左边的 2px 辅色边（MessageBubble.vue:166）同向，读起来是"同一条声部的延伸"。
2. 旁白里能不能用"她/他"指代角色。上面 C 组和第五格用了"她"。若要求一律用名字（更不会与用户的"我"混），提示词就多一条硬约束，模型违规率会上升。我的默认：允许"名字（每段首次）+ 她/他（后续）"。
3. 标记字符。倾向 ⟦ ⟧（U+27E6/27E7），因为正文里还要过 <status> 与 <think> 两层解析（chat-manager.ts:474-483），尖括号系要绕的坑更多；中文小说正文里也几乎不会出现这两个符号。
4. 心理段要不要进上下文（即下一轮喂给模型时，这段旁白留不留）。我的默认是留：它既是格式示范也是角色连续性的一部分；代价是每轮多几百 token，而输出预算已由 src/core/token-budget.ts 按最大上下文自动推导，不会因此溢出。
