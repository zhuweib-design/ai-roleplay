# AI 酒馆 0.8.0 发布说明

发布日期：2026-09-27
版本定位：让长期记忆在被用于后续对话前可由用户复核，并保留完整审核来源。

## 主要变化

### Runtime 记忆审核

- 事件自动生成的 Runtime Memory 默认为候选；候选内容不会进入对话上下文。
- Runtime 状态面板展示记忆内容、状态、置信度和来源事件，支持确认、拒绝和停用。
- 已确认的记忆按原有有效期规则参与上下文；已拒绝或停用的记忆不会再被召回。
- 旧快照缺少审核状态时仍按已确认处理，避免升级后旧记忆突然消失。

### 持久化与回放

- 审核动作写入 Runtime Event 与 StateChange，可通过事件流重放恢复。
- 审核事件使用稳定 ID；相同动作重试不会重复推进 Runtime 版本。
- PostgreSQL 为记忆增加审核状态和审核时间列；已有记录迁移后默认已确认。
- 停用只停止后续注入，保留历史内容以支持审计和回放，不代表从所有历史快照中物理擦除。
- Runtime Replay 自检从初始情绪基线构建回放起点，避免当前状态与记忆干扰重放。

### 服务端边界

- 审核请求继续经过 Runtime HTTP 认证和成员授权。
- 绑定租户的服务端会覆盖客户端请求中的租户标识；跨租户审核被拒绝。
- 通用事件接口不接受审核 effects，避免绕过专用审核请求的授权路径。
