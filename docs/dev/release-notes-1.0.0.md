# AI 酒馆 1.0.0 发布说明

发布日期：2026-09-27

版本定位：首个稳定版本，完成从本地长对话能力到可审计、多角色 Runtime 和安全发布边界的收口。

## 稳定版内容

- 0.4.0：本地长期记忆、双通道向量 RAG、长对话摘要与上下文状态展示。
- 0.5.0：全文搜索、历史消息定位、双向虚拟化和长对话性能优化。
- 0.6.0：确定性 Appraisal、Behavior Planner、长期态度与关系惰性衰减。
- 0.7.0：记忆有效期与上下文来源审计。
- 0.8.0：记忆确认、拒绝、停用和可回放审核事件。
- 0.9.0：单一本地用户与世界内扮演资料；同一用户可在不同世界使用不同角色设定。
- Runtime：批量角色、多角色群聊、租户边界、PostgreSQL 事务、CAS、outbox、Replay 和备份恢复。
- 安全与部署：核心数据契约、资源许可证校验、CSP、Web 部署 SOP、迁移 Runbook 和运行时审计。

## 数据兼容

1.0.0 不删除既有角色卡、聊天、世界书、故事、设置或旧 Persona 数据。旧快照和备份按兼容规则读取；没有新增结构性数据库迁移，现有 PostgreSQL 全量迁移脚本保持幂等。

## 已知边界

- 真实 Provider 的缓存命中率、首 token 延迟、真实对话 token 节省和人工盲评需要部署方配置凭据与样本后执行。
- Web 静态部署仍需按 SOP 配置 HTTPS、响应头 CSP、WASM MIME、SPA 回退和缓存策略。
- PostgreSQL 生产迁移、认证宿主和密钥管理由部署方负责，仓库提供边界、脚本和演练入口。
