# AI 酒馆 0.6.0 发布说明

发布日期：2026-09-27
版本定位：让 Runtime 从“记录状态”进入“解释事件并形成回应策略”。

## 主要变化

### Appraisal Engine

- 新增确定性的事件评价层，输入事件、角色人格特质、价值观、目标、对象态度、关系、历史事件和当前状态。
- 输出重要性、目标相关性、价值冲突、背叛、威胁、损失、社会显著性、意外性、目标显著性和综合影响强度。
- 支持事件 payload 中的显式评价信号；没有显式信号时使用事件类型、主题、对象关系和角色资料推导，结果可 Replay。
- 评价原因写入 StateChange 审计摘要，便于调试角色为何被某个事件触动。

### Behavior Planner

- 新增结构化行为规划层，策略包括平稳互动、温和对抗、明确边界、支持性安抚、澄清和积极互动。
- 输出目标、策略、强势度、温度、直接度、情绪表达、边界约束、表达指令和置信度。
- 规划器不生成自然语言、不调用模型、不改变 Runtime 状态，现有 LLM 只负责把策略自然语言化。

### Runtime 链路与衰减

- State Reducer 先完成 Appraisal，再应用显式 effects 或缺省的温和事件影响；显式 effects 始终优先，兼容既有事件。
- Runtime Context 和聊天桥接会提供最近的 Appraisal 与 Behavior Plan，保持人格锚点和当前状态分离。
- Attitude 与 Relationship 可配置 half-life、基线和维度基线，按访问时间惰性衰减；未配置的旧状态不自动变化。

## 兼容与升级

- 不新增数据库迁移。
- 旧快照、旧事件和旧对话继续使用原有存储格式。
- 只要没有为态度或关系配置 `halfLifeSeconds`，升级不会让已有长期状态自动回到基线。
