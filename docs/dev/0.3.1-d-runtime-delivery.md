# 0.3.1 D 阶段：Runtime 可靠投递与群聊数据契约

完成日期：2026-09-26

## 交付范围

- 本地待提交回合固定保存 `occurredAt`，重试复用同一时间和逻辑回合键，不因重试生成新的载荷。
- 本地队列记录 `pending / failed` 状态、尝试次数、错误代码、HTTP 状态和下次重试时间；兼容 0.3.0 没有这些字段的旧快照。
- 服务端 outbox 重复入队改为只读已存在条目：同键同载荷幂等返回，载荷或时间不一致返回 `409 OUTBOX_CONFLICT`，不会覆盖已提交或待重试内容。
- 群聊页切换时查询服务端 `pending / failed` outbox，将本地缺失的回合恢复到现有显式重试入口；发言角色不再属于当前群聊时保留错误并拒绝恢复。
- 已提交的服务端回合在群组归档后仍可用同一载荷确认，避免客户端未收到成功响应时重复投递失败。

## 代码落点

- `src/stores/chat.ts`：本地待提交队列字段、旧快照兼容、服务端 outbox 恢复和固定时间重试。

- `tests/runtime/postgres-group.integration.test.ts`：服务端同键时间/载荷冲突、失败状态尝试次数、归档后已提交条目确认测试。
