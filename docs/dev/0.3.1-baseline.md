## 版本边界

0.3.1 只收敛 Runtime 与群聊生产化能力：认证、租户与成员授权、HTTP 数据契约、可靠队列、状态机、生命周期、PostgreSQL 一致性、观测、故障注入和发布门禁。长对话、摘要、记忆与 RAG 继续归入 0.4.0。

## 阶段顺序

按已确认的 C → D → A 顺序执行：

1. C：Runtime 认证、租户边界和服务端请求可信来源。
2. D：Runtime/群聊数据契约、可靠投递、状态机和真实数据库验证。
3. A：质量门禁、故障注入、迁移演练、发布文档与 GitHub 交付。

每个阶段完成后必须更新本记录或对应交付文档，并创建独立本地提交。0.3.1 全部门禁通过后才推送 GitHub。
