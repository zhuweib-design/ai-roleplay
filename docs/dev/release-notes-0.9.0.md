# AI 酒馆 0.9.0 发布说明

发布日期：2026-09-27

版本定位：把用户账户与世界内扮演资料分开，确保同一个本地用户可以在不同世界使用不同的昵称、描述和角色设定。

## 主要变化

### 单一本地用户

- 个人中心只显示一个“本地用户”账户入口，并保留登录入口作为后续远程认证接线点。
- 设置页和聊天上下文不再提供或读取“当前身份”切换。
- 应用启动不再加载旧 Persona 列表作为运行时身份。

### 世界内扮演资料

- 每本世界书可保存昵称、描述、性别、代称、年龄、职业、外貌、背景和备注。
- 角色对话只读取当前角色关联的世界书资料；没有资料时使用中性默认昵称 `User`。
- 世界资料仍随世界书导入、导出和备份保存，不会覆盖其他世界的用户设定。

### 故事与导出

- 故事主角继续作为故事内容注入提示词，但不会创建或切换全局 Persona。
- 聊天 Markdown 导出按角色关联的世界资料选择用户昵称，避免跨世界复用错误身份。

## 兼容与数据说明

- 旧 Persona 类型、存储 API 和备份字段保留，便于打开旧快照和恢复旧备份；它们不再参与 0.9.0 的对话身份、故事身份或世界资料注入。
- 旧世界书没有 `userProfile` 时无需迁移；用户可在世界书页面新增资料。
- 本版本没有删除历史聊天、角色卡、世界书或 Runtime 数据。
