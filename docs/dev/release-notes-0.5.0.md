# AI 酒馆 0.5.0 发布说明

发布日期：2026-09-27
版本定位：长对话交互质量 —— 在双向虚拟化基础上提供可定位、可回看的完整消息历史。

## 主要变化

### 全文搜索

- 聊天顶栏新增消息搜索入口，查询覆盖当前角色的完整历史消息，不受当前虚拟化窗口限制。
- 支持中英文大小写、全角字符和空白归一化；搜索正文与旁白，不检索隐藏的思考字段。
- 搜索结果按消息原始顺序循环导航，显示当前命中位置、总命中数和上下文片段。

### 历史消息跳转

- 选择上一个或下一个匹配项时，虚拟化窗口会重定位到目标消息，并把目标滚动到视口中央。
- 跳转窗口重新计算顶部与底部占位高度，保留 10,000 条以上对话的恒定 DOM 规模。
- 当前命中消息增加轻量定位描边，不改变消息高度，避免滚动位置二次跳动。

### 兼容与交互

- 不新增数据库迁移；角色、会话和旧消息继续沿用现有存储格式。
- 搜索条支持键盘操作：回车前进、Shift+Enter 后退、Escape 关闭；移动断点下输入字号保持 16px。
- 既有“回到底部”、上滚加载和下滚恢复行为保持不变。

## 已知边界

- 搜索结果只包含用户可见正文和旁白，隐藏思考内容不会出现在结果中。
- 搜索结果不会跨角色或跨会话合并；切换角色后搜索状态会清空。
- 完整浏览器滚动帧率仍需在发布环境复跑，当前组件测试覆盖窗口重定位和结果导航契约。
