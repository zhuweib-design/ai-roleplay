> 本文档是本轮"Web 端 + 手机端"实机测试的**唯一记录文档**：环境、模块划分依据、每批目标与验收标准、执行结果与发现的问题、最终汇总与遗留问题全部记录于此，随测试同步更新。

## 〇、测试环境与通道（含一处客观替代）

| 项 | 实际状态 | 证据 |
|---|---|---|
| 被测构建 | Vite dev server（Web 端形态），`http://localhost:5173` | `curl` 返回 200 |
| 桌面浏览器通道 | 本机 Microsoft Edge（Playwright `msedge` project，Desktop Chrome 视口） | `playwright.config.ts:50-55` |
| 移动通道 | **Chromium/Edge 的 Pixel 5 设备仿真**（视口 393×851、touch、UA、DPR 3） | `playwright.config.ts:80-99` |
| WebKit 通道 | 本机未安装 webkit 浏览器内核，**本地不跑**，由 CI 覆盖 | `~/AppData/Local/ms-playwright` 仅有 `chromium_headless_shell` / `ffmpeg` / `winldd` |
| 虚拟机 / 真机 | **不可达**：无 VirtualBox / VMware / qemu / Android emulator / 国产模拟器安装痕迹；`adb devices` 列表为空；Hyper-V 仅 `vmcompute` 在跑、无 `VMMS` | 探测命令与输出见 §附录 A |

**替代决策（阻塞自行决断）**：目标要求"虚拟机的手机端"，但本机不存在任何虚拟机或 Android 运行时，且无 adb 设备可接管。故手机端测试改由**设备仿真 + 真实触摸事件 + PWA 视口**承担（即仓库自身 `mobile-*` project 的做法），并在本报告所有移动端结论上标注"仿真通道"。真实 Android WebView 行为（键盘避让、`dvh` 实现差异、原生分享）不在本轮可验证范围内，已列入遗留问题。

**模型使用策略**：LLM 相关用例统一走本地网关 `http://127.0.0.1:7864`（OpenAI 兼容，15 个模型），首选 `hy4-preview-f`，不可用即降级 `hy3`；每批最多 1–2 次真实调用，其余用 mock / 静态断言。

## 一、功能模块划分依据

按**路由 + 数据域 + 交互闭环**三条件交叉划分：同一批次内的用例共享一条可独立验收的业务闭环（有入口、有状态变更、有可观察结果），且尽量不跨存储域（IndexedDB store：`characters` / `chats` / `documents` / `groups` / `lorebooks` / `personas` / `settings` / `snapshots` / `stories`），以便失败时可归因到单一模块。

15 个路由视图 + 设置 6 面板 + 横切能力，归并为 9 个批次：

| 批次 | 覆盖模块（路由 / 组件 / 存储域） | 划分依据 |
|---|---|---|
| B1 | 应用骨架与导航：`App.vue` 启动、侧栏/底栏导航、`ProfileView`、`ArchivesView`、会话与角色切换 | 所有其他批次的入口前置，失败会污染后续批次，必须最先验 |
| B2 | 角色域：`CharactersView` / `CharacterEditorView` / `CharacterVersionView`（`characters` 域、版本 diff 与回滚） | 单一数据域的完整 CRUD + 版本闭环 |
| B3 | 对话核心：`ChatMain`、消息发送/流式/重新生成/编辑/删除/复制/翻译/朗读、消息搜索、导出、上下文面板（Token 预算 / 摘要 / 作者笔记 / Runtime 状态 / 生成参数 / 状态指令） | 项目主链路，跨 `chats` + `characters` + runtime 三域，用例最多 |
| B4 | 设定域：`WorldBookView`（`lorebooks`）、`DataBankView`（`documents`）、`RandomEventsView` | 同为"注入进提示词的素材"，验收点都是检索命中与注入效果 |
| B5 | 群聊：`GroupChatView`（`groups`、成员、轮次、游标分页、可靠投递） | 独立数据域 + 独立 Runtime 分支 |
| B6 | 创作扩展：`StoryEngineView`（`stories`）、`ImageGeneratorView` | 依赖外部模型能力、与主链路解耦 |
| B7 | 模型与检索：设置内 API 配置 CRUD / 测试连接 / 获取模型列表 / 主模型切换、`LocalModelView`、RAG 双通道、用户自定义向量模型、ORT 首屏隔离 | 全部围绕"模型供给"，且直接决定 B3/B4/B6 能否真跑 |
| B8 | 设置其余：外观（主题/字号/背景/气泡/自定义 CSS）、扩展、数据（备份/恢复/导入导出）、安全（主密码与透明加密）、关于、`CommunityMarketView` | 同一 `settings` 域 + 文件系统边界，验收点是持久化与加密 |
| B9 | 横切：i18n 中英切换、响应式与移动端布局、无障碍（对比度 / ARIA / 键盘）、CSP 与错误重试、刷新持久化 | 不属于任一业务域，但每个域都会被它影响 |

→ **测试基础设施待办（P3）**：本机并行跑多 project 时 30s 导航超时偏紧，建议 `playwright.config.ts` 对 axe 类重页面用例单独放宽 `timeout`，或本地默认 `workers=1`。

**还原耗时**：`[MIG-02] 还原耗时 210ms`（本地上限 15000ms）。

## 四、缺陷与观察清单

| 编号 | 级别 | 现象 | 定位与判断 |
|---|---|---|---|
| **D-1** | **P2（功能不可用）** | 社区市场"加载远程条目"恒返回 `HTTP 404` | `src/core/market-index.ts:73` 硬编码 `https://raw.githubusercontent.com/zhuweib-design/ai-roleplay/**main**/market/index.json`，而本仓库默认分支是 **`master`**（`git ls-remote --symref origin HEAD` → `ref: refs/heads/master`）；且仓库为**私有**，匿名 raw 请求本就 404。两处叠加 ⇒ 远程市场功能当前**不可能工作**。修法需产品决策：改分支名 + 转公开，或改为带鉴权的拉取，或明确标注该功能仅对公开镜像生效 |

## 七、收尾说明

**模型用量（按"节省着用"执行）**：对话页端到端真实调用 **1 次**（`hy4-preview-f`，约 112 tokens）；网关直连探测 3 次（各 ≤64 tokens）；故事引擎异步结构化提取 1 组（40 字 / 2 块，用量极小）；另有 1 次对话尝试失败于上游 503。首选模型全程可用，未触发切换。其余全部为静态断言、IndexedDB 读取或既有 E2E 复用。

**测试数据残留**：本轮在 **Qoder 内置浏览器**的 IndexedDB（`ai-roleplay`）中留下：1 个角色（`QA-B2-测试角色`）、1 个世界书、1 个文档（`qa-doc.md`）、1 个群聊（`QA-B5-测试群`）、若干版本提交，并在该会话内设置了主密码（不落盘）。该数据库与用户自己的浏览器相互隔离，不影响真实使用数据；如需清理，删除该浏览器站点数据即可。

**环境替代声明**：目标中的"虚拟机手机端"在本机不可达（无虚拟机 / 无 Android 运行时 / 无 adb 设备），已统一以 Pixel 5 设备仿真替代，所有移动端结论均带此限定。桌面端（Tauri）因本机无 cargo 且按约束不产出安装包，仅达"CI 编译通过 + 静态审查"级别，原生对话框、托盘、全局快捷键、磁盘模型导入未做运行时验证。

**与既有门禁的关系**：本轮实机结论与 CI #84（Quality Gates 17 步全跑、E2E、Tauri Build 全绿）互相印证；本轮新发现的 D-1（市场远程清单 404）与 O-6（对比面板渲染）均不在现有自动化覆盖范围内 —— D-1 属外部依赖配置，O-6 属 UI 组件条件渲染，若要长期拦截需补对应 E2E 用例。
