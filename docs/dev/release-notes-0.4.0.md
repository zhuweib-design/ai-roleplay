# AI 酒馆 0.4.0 发布说明

发布日期：2026-09-26
版本定位：长对话基础能力 —— 让本地记忆、向量检索和摘要在现有对话存储上连续工作，并保持旧数据可用。

## 主要变化

### 本地长期记忆

- 记忆事实和情绪快照保存到现有 `StorageAdapter`，按当前 API Profile 隔离。
- 应用启动时恢复快照；损坏的单条记录会跳过，不阻断聊天主链路。
- 每轮完成后记录可检索的会话事实，下一轮按当前消息检索并注入动态上下文。

### 双通道向量 RAG

- 数据银行文档、世界描述、世界书条目进入静态索引，会话记忆进入动态索引。
- 来源内容未变化时不重复嵌入；删除来源会从索引移除；切换嵌入模型会清空旧模型索引，避免向量维度混用。
- 关键词 RAG 与向量 RAG 合并去重，并限制注入长度。

### 长对话摘要

- 摘要任务按会话串行化，避免快速连续发送时旧结果覆盖新结果。
- 编辑、删除和重新生成消息会让旧摘要失效；摘要生成完成前会检查消息基线。
- 上下文面板显示摘要是否已经生成、覆盖消息数以及是否正在更新。

## 数据兼容

0.4.0 没有新增数据库迁移文件。已有角色、世界书、对话、设置和旧聊天消息继续沿用原存储格式；本地记忆使用新的 Profile 级快照键，只有产生记忆后才会创建。旧聊天不会被重写或删除，摘要也按会话逐步生成。

## 已知边界

- 本地长期记忆属于客户端数据；远程 Runtime 的事件、记忆和群聊事务仍由其既有服务端边界管理。
- 摘要失败时聊天继续按原历史运行，不会阻塞消息发送。
- 本次版本没有改变远程登录、账户和多角色结构。
